# Árvore AVL em C (Implementação e Validação Exaustiva)

Este repositório contém uma implementação de uma Árvore AVL (Árvore Binária de Busca Balanceada) escrita em C. 

Estre projeto utiliza uma rotina de testes (`brute_force_avl_validation`), que utiliza o algoritmo de Narayana Pandita para gerar e testar **todas as permutações lexicográficas possíveis** de inserção e remoção para um dado conjunto de entrada.

## Documentação

A documentação completa das funções, estruturas e diagramas de chamadas pode ser acessada aqui:
**[Documentação Completa](https://fl4hv1a.github.io/AVL-Tree-Algorithm/html/index.html)**

## Como Compilar e Rodar

O código não possui dependências externas além da biblioteca padrão do C. Para compilar usando o GCC:

```bash
gcc -Wall -Wextra src/AVL.c -o build/output.exe # Compile

./build/output.exe # Run
```
