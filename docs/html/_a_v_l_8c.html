Verifica se uma subárvore BST possui exatamente as mesmas chaves (considerando-se um percurso em-ordem) de um vetor de referência.

Função de comparação para ordenação crescente de inteiros.

Converte os ponteiros genéricos (void *) para ponteiros de inteiros (int *) e subtrai os valores apontados para determinar a ordem relativa entre eles.

Parameters

Returns
O resultado da comparação.
Return values

-0: Se a for igual a b;

Pode ser utilizado como "`int_comp(a, b)` `op` `0`" (onde op é o operador de comparação desejado).

- "`int_comp(a, b)` `>=` `0`" - Testa se `a >= b`;

◆ perm_next()

bool perm_next ( int * arr,
int tamanho )

Gera a próxima permutação lexicográfica de um arranjo.

Implementa o algoritmo de Narayana Pandita. O algoritmo se inicia encontrando o maior índice i tal que arr[i] < arr[i+1]; Depois, encontra o maior índice j > i onde arr[j] > arr[i]; Posteriormente, troca os elementos de i e j usando swap(); Por fim, inverte a ordem do sufixo a partir de i+1 usando perm_invert(). Se o arranjo estiver em ordem decrescente (a última permutação possível), a função retorna false.

Parameters
[in,out]arrPonteiro para o arranjo de inteiros que será permutado.
[in]tamanhoQuantidade de elementos contidos no arranjo.
Returns
Status da geração da nova permutação.
Return values
-true: se uma nova permutação foi gerada com sucesso;
-false: se não houver mais permutações possíveis (o arranjo chegou à sua ordem reversa máxima).

Verifica recursivamente se todos os nós de uma subárvore respeitam as propriedades BST.

Parameters
[in]nPonteiro para o nó raiz da subárvore a ser validada.
[in]min_nodePonteiro para o nó que servirá como limite inferior exclusivo (ou NULL se não houver limite).
[in]max_nodePonteiro para o nó que servirá como limite superior exclusivo (ou NULL se não houver limite).
Returns
Resultado da validação da subárvore.
Return values
-true: Se todos os nós estiverem dentro dos limites permitidos;
-false: Caso algum nó seja encontrado fora dos limites permitidos.
